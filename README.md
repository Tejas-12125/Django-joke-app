# Django Joke App 😂

A simple Joke Application built using the Django Framework and Python.

## Features

- Displays a random joke.
- Uses the `pyjokes` Python library.
- Simple and clean web interface.
- Built using Django templates and views.

## Technologies Used

- Python
- Django
- HTML
- CSS
- PyJokes
